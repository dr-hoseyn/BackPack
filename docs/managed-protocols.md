# Managed Hysteria2, AnyTLS, ShadowTLS and TUIC

Use **BackPack v1.10.0 or later on both machines**. These modes use the installer-pinned official **sing-box
v1.14.2**, installed by default on supported Linux glibc amd64/arm64 machines.
From this source checkout: `BP_BUILD_FROM_SOURCE=1 BP_HELPERS=naive,xray bash install.sh`.
`BP_HELPERS=naive` also installs sing-box; no protocols are reimplemented here.

| Protocol | Outer traffic | Reverse forwarding | Native datagram L3 |
|---|---|---|---|
| Hysteria2 | QUIC/UDP, optional Salamander | TCP; stream UDP or opt-in native UDP | Yes, Salamander and adaptive BBR |
| AnyTLS | TLS/TCP with padding and connection reuse | TCP and opt-in UDP in reliable streams | No |
| ShadowTLS v3 + SS2022 | Verified TLS cover, encrypted inner TCP | TCP and opt-in UDP in reliable streams | No |
| TUIC v5 | QUIC/UDP with BBR | TCP; stream UDP or opt-in native UDP | Yes, native UDP relay |

For native game/voice datagrams choose **Direct → Hysteria2 / TUIC**. Reverse
UDP defaults to the existing length-prefixed reliable stream format. The new
`native_udp` option below enables actual datagrams for Hysteria2/TUIC. AnyTLS and
ShadowTLS are reliable streams and cannot be L3 carriers. None of these modes
implies compatibility with an HTTP reverse proxy or CDN. Hysteria2/TUIC need a
usable UDP path; Salamander cannot restore a completely blocked IP or UDP path.

## Reverse setup

On Iran choose **Setup Iran → Reverse → HTTPS → the protocol**. The public
listener and private reverse port must differ. The wizard collects helper
settings, generates independent credentials, and prints Kharej's Setup Link.
On Kharej choose the same protocol and paste that link, or use
`backpack link apply 'backpack://…'` with matching builds.

The link transfers paired credentials and public private-CA trust when needed.
It never transfers the server's TLS private key or executable paths. Edit the
endpoint and credentials together with **HTTPS Settings**; ordinary edits
retain them. The panel monitors and manages these tunnels; credential creation
uses the terminal. Keep configs and links private, mode `0600`.

Manual example (keep the usual reverse pool/heartbeat tuning):

```toml
# Iran
[server]
bind_addr = "127.0.0.1:3080"
transport = "tcp"
token = "REPLACE-WITH-A-LONG-RANDOM-REVERSE-TOKEN"
ports = ["8080=127.0.0.1:8081"]
accept_udp = false

[server.sing]
binary = "/usr/local/lib/backpack/helpers/sing-box/v1.14.2-amd64/sing-box"
protocol = "hysteria2"
listen = "0.0.0.0:443"
server_name = "iran.example.com"
password = "REPLACE-WITH-A-DIFFERENT-RANDOM-HELPER-PASSWORD"
obfs_password = "REPLACE-WITH-A-SEPARATE-SALAMANDER-PASSWORD"
certificate = "/etc/backpack/tls/fullchain.pem"
key = "/etc/backpack/tls/privkey.pem"
```

```toml
# Kharej
[client]
remote_addr = "127.0.0.1:3080"
transport = "tcp"
token = "REPLACE-WITH-THE-SAME-REVERSE-TOKEN"

[client.sing]
binary = "/usr/local/lib/backpack/helpers/sing-box/v1.14.2-amd64/sing-box"
protocol = "hysteria2"
server = "iran.example.com:443"
server_name = "iran.example.com"
password = "REPLACE-WITH-THE-SAME-HELPER-PASSWORD"
obfs_password = "REPLACE-WITH-THE-SAME-SALAMANDER-PASSWORD"
# ca_file = "/etc/backpack/tls/iran-public-ca.pem" # private CA only
```

- **AnyTLS:** use `protocol = "anytls"` and remove `obfs_password` on both ends.
- **TUIC:** use `protocol = "tuic"`, remove `obfs_password`, and add the same
  canonical `uuid` on both ends. The bounded wrapper uses BBR and native UDP
  mode internally; QUIC 0-RTT is disabled.
- **ShadowTLS:** use `protocol = "shadowtls"`, remove `obfs_password` and the
  server certificate/key. Both sides use the verified cover hostname as
  `server_name`. Iran additionally sets `handshake = "cover.example.com:443"`.
  Both sides set the same `shadowsocks_key`, generated by `openssl rand -base64 32`.
  The inner method is `2022-blake3-aes-256-gcm`; ShadowTLS uses v3, strict mode,
  no wildcard SNI forwarding and a Chrome fingerprint. A private cover requires
  an explicit public CA on the client. The cover must differ from the helper
  and reverse listeners.

TLS verification is always enabled. Renewal is external: valid certificate/key
or CA replacements reload the tunnel; invalid replacements retain the running
generation. Helpers receive embedded validated material. One inline managed helper
family is allowed per tunnel; [managed paths](managed-paths.md) explicitly
configures multiple independent helpers. Internal transport stays `tcp`; other outbound
proxies, routing bindings and endpoint/transport fallbacks are rejected rather
than silently bypassed. Helpers can reach only the exact private loopback IP
and port. Local listener readiness is not authenticated tunnel health.

## Native UDP in Reverse mode

Requires this next-protocols build on both machines. For Hysteria2 or TUIC,
set `accept_udp = true` in `[server]` and **`native_udp = true` in both
`[server.sing]` and `[client.sing]`**. The wizard offers this explicitly and
Setup Links carry the paired flag. Leave it false to retain stream UDP.
The private Reverse address is shared by TCP and a UDP broker; both must be free
on the same literal loopback address/port. Forwarded UDP ports retain the
ordinary `server.ports` mappings, including independent flows and ranges.
No TUN or new firewall rules are installed.

The Internet path uses sing-box's native QUIC datagrams through a local SOCKS5
UDP association. A separate Noise NNpsk0 handshake derives directional AEAD keys
from the Reverse token. Counter replay protection is committed only after
successful authentication. Periodic key rotation, bounded pending handshakes,
authenticated keepalives, a hard session lifetime and previous-key overlap
bound recovery state. Probes use domain-separated request/response MACs and
cannot replace a live Noise association. Keep machine clocks correct: session
ordering uses authenticated timestamps and refuses older handshakes.

Packets retain their boundaries and are never retransmitted by this Reverse
UDP layer. Outage packets and over-limit packets are dropped; recovery does
not replay them. Application flows can still time out during recovery.
The association message budget is 60,000 bytes; application datagrams must also
fit the flow ID and target metadata inside that budget.
Messages larger than 1,000 bytes use independently authenticated fragments.
At most 64 incomplete messages are retained, each for at most three seconds.
Fragments can arrive out of order; a missing fragment drops only its message
and never holds later datagrams. There are no fragment acknowledgements or
retries. Large datagrams have a higher chance of loss when a path drops packets.

Optional local settings in each sing table:

```toml
native_udp = true
udp_max_flows = 128       # default 128, maximum 4096
udp_bandwidth_mbps = 20   # 0 = unlimited; excess datagrams are dropped
```

Flow state expires after 60 idle seconds and each flow has a four-packet setup
queue. Limits are local; all native paths in one process must use identical
local limits. Existing stream-wide `max_connections` or `bandwidth_mbps` on Iran
are rejected with native UDP: use the explicit UDP limits rather than assuming
the stream limiter covers these sockets. Metrics distinguish association
health, active flows, sent/received/dropped datagrams and byte totals. Ordinary
tunnel byte counters include native UDP for traffic accounting.

## Native Hysteria2 / TUIC for L3

Choose **Setup Iran → Direct → UDP → Hysteria2 / TUIC**. Iran dials Kharej.
Both sides need the helper, Linux TUN and network administration privileges.
Kharej owns its TLS certificate/key. Iran verifies the identity using system
trust or a separately transferred public CA. Native setup links carry the
paired target and verified name, without local file paths or server keys.
Kharej's terminal flow asks for TLS files; link apply also accepts
`--sing-binary`, `--sing-cert`, `--sing-key` and `--sing-ca` as local options.

Native settings are flat keys in `[l3]`, beside the normal mode, address,
token, interface, inner addresses and optional port mappings:

```toml
carrier = "hysteria2" # or tuic, identically on both sides
sing_binary = "/usr/local/lib/backpack/helpers/sing-box/v1.14.2-amd64/sing-box"
sing_target = "127.0.0.1:62102" # identical; a distinct port per tunnel
sing_server_name = "kharej.example.com"
# Kharej/listen only:
sing_cert = "/etc/backpack/tls/fullchain.pem"
sing_key = "/etc/backpack/tls/privkey.pem"
# Iran/dial with a private CA only, omitting the two keys above:
# sing_ca = "/etc/backpack/tls/kharej-public-ca.pem"
```

Native helper credentials derive separately from the L3 token. Hysteria2 uses
Salamander in this L3 mode. SOCKS5 UDP ASSOCIATE exists only on loopback; the
Internet path uses native datagrams, without a stream fallback. Associations
reconnect after helper restart. Outage packets are lost rather than queued.
The existing Noise authentication, MTU calculation, FEC and L3 forwarding apply.
Multipath remains specific to the plain UDP carrier. Application connections
can time out while the outer session and Noise handshake recover.

## Test scope

Connection Test includes all four reverse modes and the two native Direct
carriers. Missing helpers are skipped tests, not network failures. Real
authentication, payload verification and throughput are required; a TLS probe
alone never marks a tunnel healthy.

Automated tests cover the pinned helper, denied destinations, bad credentials,
untrusted certificates, concurrent TCP, replies after directional EOF, forwarded
UDP, native datagram boundaries, helper restart and Noise/IP payloads. Disposable
Linux namespaces exercise real TUN interfaces over IPv4/IPv6, packet loss and
peer restart. These establish implementation behavior; they do not establish
performance or reachability on a particular ISP or Iran/outside route.

The independent managed AWG engine is documented in [AmneziaWG](amneziawg.md).

## خلاصهٔ فارسی

هر دو سرور باید BackPack نسخهٔ v1.10.0 یا بالاتر و sing-box رسمی نسخهٔ 1.14.2 داشته باشند.
از منوی Reverse → HTTPS می‌توان Hysteria2، AnyTLS، ShadowTLS v3 و TUIC v5
را با لینک جفت‌شده ساخت. گواهی TLS همیشه بررسی می‌شود؛ لینک و فایل تنظیمات
حاوی اطلاعات خصوصی‌اند. کلید خصوصی گواهی سرور در لینک منتقل نمی‌شود.

UDP در Reverse به‌صورت پیش‌فرض داخل جریان مطمئن است. در نسخهٔ جدید، با
`native_udp = true` در هر دو سر Hysteria2/TUIC دیتاگرام بومی فعال می‌شود؛
بستهٔ ازدست‌رفته تکرار نمی‌شود. برای حالت L3 از
Direct → UDP → Hysteria2 یا TUIC استفاده کن؛ این حالت به TUN و دسترسی مدیریت
شبکه نیاز دارد. AnyTLS و ShadowTLS حامل L3 نیستند. ساخت جفت و تنظیم گواهی از
ترمینال انجام می‌شود و پنل، مدیریت و وضعیت تونل نصب‌شده را ارائه می‌کند.

تست‌های خودکار انتقال واقعی، احراز هویت نامعتبر، IPv4/IPv6، افت بسته و
راه‌اندازی مجدد را بررسی می‌کنند. این نتایج تضمین دسترسی یا سرعت روی مسیر
واقعی اینترنت ایران نیستند؛ آن مسیر باید جداگانه آزمایش شود.
